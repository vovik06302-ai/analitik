# Pearl AI Analyst

Приложение на **React + TypeScript + Express + SQLite + Electron** для визуального, рыночного и новостного ИИ-анализа криптопары **PEARL/USDT** через **Gemini API** (`@google/genai`), **Ollama** и **Claude API**.

> **Важно:** программа предназначена **только для анализа**. В ней нет автоматической торговли, доступа к кошелькам, средствам или API-ключам биржи. Все прогнозы носят информационный характер: *«Приблизительная оценка, не финансовый совет»*.

## Возможности (v1.0.26)

1. **Живой рынок PEARL/USDT с резервированием бирж (`/api/market`)**:
   - Приоритетный опрос **SafeTrade** с автоматическим переключением на **Gate.io (`PEARL_USDT`)** при блокировке HTTP 403 и межбиржевой сверкой по **Coinbase**, **Kraken** и **GeckoTerminal (NEAR DEX)**.
   - Многотаймфреймовые свечи с объёмами (`15m`, `1h`, `4h`, `1d`), стакан по зонам `±0.5% / ±1% / ±2%`, крупнейшие стены ликвидности и поток сделок (**CVD / % покупок**).
   - Макроконтекст **BTC/USDT** и **ETH/USDT** (динамика 1ч/4ч/24ч и тренд).
2. **Серверный расчёт технических индикаторов**:
   - Детерминированный расчёт **EMA 9/21/50/200**, **RSI(14)** с дивергенциями, **MACD(12,26,9)**, **ATR(14)**, **Bollinger Bands(20,2)** и сжатия (squeeze), **VWAP**, **Volume Profile POC**, свингов `HH/HL / LH/LL` и выравнивания по таймфреймам.
3. **Управляемый горизонт прогноза (1ч / 2ч / 4ч), Guardrails и Совет ИИ (`/api/analyze`, `/api/analyze/consensus`)**:
   - Явный выбор горизонта прогноза, строгая валидация логических инвариантов (Цель/Стоп/Уровни/R:R/ATR) с автоматическим ретраем при нарушении.
   - Взвешенный Совет ИИ (`Gemini`, `Claude`, `Ollama`) с учётом исторического Win Rate каждой модели и прозрачным уведомлением при резервном переключении модели.
   - Разделение разового анализа («Анализировать сейчас») и отдельной кнопки включения авто-анализа.
4. **Приоритетный радар новостей (`/api/news`)**:
   - Фильтрация некриптового шума по слову `Pearl`, гарантированная квота прямых новостей по `PEARL / SafeTrade` и учёт отрицаний в тональности.
5. **SQLite-история и проверка «Цель vs Стоп» (`/api/history`, `/api/history/verify`)**:
   - Проверка факта по 5-минутным экстремумам High/Low внутри окна горизонта (`Цель ✓` / `Стоп ✕` / `Истёк`), адаптивный порог боковика по `ATR%`, калибровка уверенности `≥70%` и передача контекста 3 последних прогнозов в промпт.
6. **Настольная версия Windows (Electron)**:
   - Сворачивание в системный трей при закрытии окна, контекстное меню трея и настройка автозапуска Windows.
   - Уведомления в Telegram и Webhook (`/api/alerts/test`) с поддержкой переменных окружения.

## Переменные окружения

См. `.env.example`:

- `GEMINI_API_KEY` — серверный ключ для Gemini API (`@google/genai`).
- `ANTHROPIC_API_KEY` — опциональный серверный ключ для Claude API.
- `OLLAMA_URL` — адрес сервера Ollama (по умолчанию `http://localhost:11434`).
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ALERT_WEBHOOK_URL` — опциональные серверные настройки алертов.

## Запуск, тесты и сборка

```bash
npm install
npx --yes tsx --test server/*.test.ts src/utils/*.test.ts
npm run lint
npm run build
npm run build:desktop
npm run dev
```

Сервер запускается на `http://0.0.0.0:3000`.
