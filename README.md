# Pearl AI Analyst (Web Edition)

Веб-приложение на **React + TypeScript + Express + SQLite** для визуального, рыночного и новостного ИИ-анализа криптопары **PEARL/USDT** (биржа SafeTrade) через **Gemini API** (`@google/genai`), **Ollama** и **Claude API**.

> **Важно:** программа предназначена **только для анализа**. В ней нет автоматической торговли, доступа к кошелькам, средствам или API-ключам биржи. Все прогнозы носят информационный характер: *«Приблизительная оценка, не финансовый совет»*.

## Возможности (v1.1.0)

1. **Живой рынок PEARL/USDT и радар аномалий (`/api/market`)**:
   - Автоматическое получение актуального курса SafeTrade `PEARL/USDT`, 24ч объёма, спреда, диапазона Min/Max, 48 свечей OHLC (30м) и сравнения цен с других бирж (`BigONE`, `Gate`, `Coinbase`, `DexScreener`).
   - Автоматическое обнаружение резких ценовых движений, повышенного спреда SafeTrade и межбиржевых расхождений.
2. **Совет ИИ — консенсус нескольких моделей (`/api/analyze/consensus`)**:
   - Параллельный опрос всех настроенных провайдеров (`Gemini`, `Claude`, `Ollama`), расчёт процента согласия, предупреждение при расхождении мнений и сводная таблица голосов.
   - Серверный ключ `GEMINI_API_KEY` зашифрован в памяти процесса (`AES-256-GCM`).
3. **Захват экрана и живой поток (`getDisplayMedia`)**:
   - Интерактивное выделение области графика, загрузка файла перетаскиванием или вставка через `Ctrl+V`.
   - Опция удержания живого видеопотока окна/вкладки для автоматического снятия свежего скриншота перед каждым запуском по таймеру.
   - Визуальный **HUD уровней** (Цель, Стоп, Поддержка, Сопротивление) поверх превью графика.
4. **Радар новостей (`/api/news`)**:
   - Сбор новостей из RSS-лент (`CoinDesk`, `Cointelegraph`, `Decrypt`, `CryptoSlate`) и Google News по ключевым словам.
   - Автоматическая оценка релевантности (`PEARL / SafeTrade` vs общий рынок) и тональности (`Бычий`, `Медвежий`, `Нейтральный`) с фильтрами по свежести (24ч/48ч) и тону.
5. **SQLite-история, аудит и проверка точности (`/api/history`, `/api/history/verify`)**:
   - Постоянное хранение прогнозов в локальной базе SQLite (`./data/pearl_analyst.db`) вместе со скриншотом, рыночной ценой и снимком новостей.
   - Проверка фактической точности направления на горизонтах **1, 2 и 4 часа** по реальным рыночным данным, калибровка уверенности `≥70%` и средняя ошибка цели.
6. **Уведомления в Telegram и Webhook (`/api/alerts/test`)**:
   - Отправка сигналов в Telegram-бота и Discord/n8n/кастомные Webhook при высокой уверенности, смене направления или рыночных аномалиях.

## Переменные окружения

См. `.env.example`:

- `GEMINI_API_KEY` — серверный ключ для Gemini API (`@google/genai`).
- `ANTHROPIC_API_KEY` — опциональный серверный ключ для Claude API.
- `OLLAMA_URL` — адрес сервера Ollama (по умолчанию `http://localhost:11434`).

## Запуск и тесты

```bash
npm install
npx --yes tsx --test server/*.test.ts src/utils/*.test.ts
npm run build
npm run dev
```

Сервер запускается на `http://0.0.0.0:3000`.
