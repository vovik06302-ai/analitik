# Pearl AI Analyst

Нативное Windows-приложение на **C# / .NET 10 (WPF)** для визуального и новостного ИИ-анализа графика криптопары **PEARL/USDT** (биржа SafeTrade).

> **Важно:** программа предназначена **только для анализа**. В ней нет автоматической торговли, доступа к кошелькам, средствам или API-ключам биржи. Все прогнозы носят информационный характер: *«Приблизительная оценка, не финансовый совет»*.

## Что делает программа

1. **Захват области графика (Multi-Monitor + DPI)**:
   - Кнопка «Выбрать область» открывает затемнённый оверлей на весь виртуальный рабочий стол.
   - Выделенная область сохраняется в настройках и корректно снимается на мониторах с разным масштабированием DPI.
   - Скриншоты сохраняются в `%AppData%\PearlAiAnalyst\shots` и отображаются в предпросмотре.
2. **Сбор реальных новостей**:
   - Получение свежих новостей из настраиваемых RSS/Atom-лент и поисковых запросов по ключевым словам (по умолчанию: `"Pearl PRL"`, `"Pearl Research Labs"`).
   - Если новостей не найдено, отображается честный статус `новостей не найдено`.
3. **ИИ-анализ с поддержкой изображений**:
   - По умолчанию используется локальный **Ollama** (`http://localhost:11434`, `/api/chat` с картинкой в Base64).
   - Список установленных моделей загружается автоматически из `/api/tags` (по умолчанию `qwen2.5vl:32b`, запасная `qwen2.5vl:7b`).
   - Опциональный провайдер **Claude API** (API-ключ шифруется на компьютере через Windows **DPAPI**).
   - Строгий разбор JSON (`price_now`, `direction`, `confidence`, `support`, `resistance`, `target_price`, `stop_price`, `chart_reasons`, `news_impact`, `news_reasons`, `risks`) с автоматической повторной попыткой при ошибке формата.
4. **Автоматический режим и трей**:
   - Запуск анализа каждые *N* минут по таймеру.
   - Уведомления Windows в системном трее при смене направления или превышении порога уверенности.
   - Сворачивание в трей при закрытии окна.
5. **История в SQLite, точность и CSV**:
   - Все прогнозы сохраняются в локальную БД SQLite (`%AppData%\PearlAiAnalyst\history.db`).
   - Расчёт фактической точности направления через **1, 2 и 4 часа** по следующим прогнозам с известной ценой (при малом объёме данных отображается `недостаточно данных`).
   - Экспорт истории в CSV (UTF-8 с BOM для Excel).
6. **Автообновление через GitHub (Velopack)**:
   - Автоматическая проверка новых релизов при старте и кнопка «Проверить обновления» в настройках.
   - Логи работы сохраняются в `%AppData%\PearlAiAnalyst\logs`.

## Установка

1. Перейдите на страницу **Releases** репозитория:
   `https://github.com/vovik06302-ai/pearl-ai-analyst/releases`
2. Скачайте файл **`PearlAiAnalyst-Setup.exe`** из последнего релиза.
3. Запустите установщик — программа установится и появится в меню «Пуск». Дальнейшие обновления будут устанавливаться автоматически из интерфейса.

## Настройка Ollama

1. Скачайте и установите Ollama для Windows с официального сайта `https://ollama.com`.
2. Убедитесь, что Ollama запущен (или выполните в терминале):
   ```powershell
   ollama serve
   ```
3. Скачайте мультимодальную модель с поддержкой изображений:
   ```powershell
   ollama pull qwen2.5vl:32b
   ```
   Если видеопамяти недостаточно, установите более лёгкую модель:
   ```powershell
   ollama pull qwen2.5vl:7b
   ```
4. В Pearl AI Analyst откройте «Настройки» и нажмите «Обновить модели» — список доступных моделей загрузится автоматически.

## Сборка из исходников (локально)

Требуется установленный **.NET 10 SDK** на Windows 10/11:

```powershell
dotnet restore PearlAiAnalyst.sln
dotnet build PearlAiAnalyst.sln -c Release
dotnet run --project PearlAiAnalyst/PearlAiAnalyst.csproj
```

## Как выпустить новую версию

Сборка и публикация релиза на GitHub настроены через `.github/workflows/release.yml` (Velopack `vpk pack` + `vpk upload github`):

1. Обновите `<Version>` в `PearlAiAnalyst/PearlAiAnalyst.csproj` (например, `1.0.1`).
2. Зафиксируйте изменения в Git:
   ```powershell
   git add .
   git commit -m "Release v1.0.1"
   ```
3. Создайте и отправьте тег формата `v*`:
   ```powershell
   git tag v1.0.1
   git push origin main --tags
   ```
4. GitHub Actions автоматически соберёт self-contained сборку под `win-x64`, упакует установщик **`PearlAiAnalyst-Setup.exe`** и опубликует новый релиз на GitHub.
